## D. Uncertain provenance — ⛔ decisions needed before touching

1. **vlessreality-mobile/reality** — single file adapted from **Xray-core (MPL-2.0!)**. ⚠️ Compliance gap: missing from THIRD_PARTY_NOTICES. MPL = file-level copyleft; keep header/license notice in file. *Proposal: add MPL-2.0 entry to notices (doc-only fix).*
2. **hysteria2-mobile/hysteria2/** — no README/licensing headers found in repo; likely binding wrapper around apernet/hysteria2, authorship of wrapper unclear.
3. **snowflake-mobile/snowflake/** — flat package of sources; whether wrapper is anonvector-authored or upstream copy unclear.
4. **meek-mobile/** — contains ONLY `go.sum`. Likely uninitialized placeholder (same class as empty `dnstt-mobile/`, `lyrebird/`). *Proposal: treat as dead placeholder, exclude from claims, no action without approval.*
5. **app/src/main/res/raw/resolvers.txt** + generated `resolvers_data.h` — public DoH/DNS endpoint lists; provenance of curation unknown (likely functional data, low risk).

## Wire-contract constraints for ANY replacement
- `vpntz://` / `tzvpn://`(legacy read-only) profile URIs · `vless://` · `hysteria2://` imports
- Encrypted single-profile (`vpntz-enc://`) and bundle (`vpntz-bundle-enc://`) payloads readable from older releases
- Tunnel-type strings in DB/exports (`dnstt`, `noizdns`, `vaydns`, `slipstream`, …) — shared with tzgate config generator
- Rust JNI symbol names tied to Kotlin FQCNs of kept engine adapters
