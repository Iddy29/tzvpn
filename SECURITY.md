# Security Policy

## About This Project

VPN-TZ is an open-source anti-censorship tool that provides DNS tunneling to help users bypass internet restrictions. It is a **client-side privacy tool** — it does not target, exploit, or attack any systems or networks.

This project is comparable to other well-known anti-censorship tools:
- [Tor Project](https://www.torproject.org/)
- [Psiphon](https://psiphon.ca/)
- [Outline VPN](https://getoutline.org/)
- [dnstt](https://www.bamsoftware.com/software/dnstt/)

## Reporting a Vulnerability

If you discover a security vulnerability in VPN-TZ, please report it responsibly:

1. **Do NOT open a public issue**
2. Open a private [security advisory](https://github.com/vpntz/vpn-tz/security/advisories/new) on GitHub
3. Include details about the vulnerability and steps to reproduce

We take security reports seriously and will respond promptly.

## Responsible Use

VPN-TZ is intended for lawful use to protect privacy and access information freely. Users are responsible for complying with the laws of their jurisdiction.
