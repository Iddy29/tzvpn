# Security Policy

## About This Project

TZVPN is an open-source anti-censorship tool that provides DNS tunneling to help users bypass internet restrictions. It is a **client-side privacy tool** — it does not target, exploit, or attack any systems or networks.

This project is comparable to other well-known anti-censorship tools:
- [Tor Project](https://www.torproject.org/)
- [Psiphon](https://psiphon.ca/)
- [Outline VPN](https://getoutline.org/) by Google Jigsaw
- [dnstt](https://www.bamsoftware.com/software/dnstt/) by a Tor Project contributor
- [GoodbyeDPI](https://github.com/ValdikSS/GoodbyeDPI)

## Reporting a Vulnerability

If you discover a security vulnerability in TZVPN, please report it responsibly:

1. **Do NOT open a public issue**
2. Open a private [security advisory](https://github.com/Iddy29/tzvpn/security/advisories/new) on GitHub
3. Include details about the vulnerability and steps to reproduce

We take security reports seriously and will respond promptly.

## Responsible Use

TZVPN is intended for lawful use to protect privacy and access information freely. Users are responsible for complying with the laws of their jurisdiction.
